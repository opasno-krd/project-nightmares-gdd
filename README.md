# Project Nightmares: Game Design Document

**Автор:** @overmind_krd (tg)
**Роль:** Game Designer (Systems / Combat / Economy)  
**Движок:** Unreal Engine 5 (Concept)
**Локация:** Россия (Open to Remote/Relocation)  

## О проекте
Это комплексный Game Design Document для хардкорной Action-RPG/MMO с элементами психологического хоррора. Документ описывает не просто сеттинг, а **взаимосвязанные игровые системы**, направленные на создание глубокого, социального и справедливого геймплея с защитой от RMT и токсичности.
Design Philosophy: "Мы намеренно используем дефицит ресурсов (очков навыков, книг, слотов) для создания осмысленного выбора. Мы принимаем существование локальных 'мет', так как они являются результатом глубокой специализации, а не отсутствия баланса. Экономика защищена не запретами, а экономической нецелесообразностью нарушений."

## Структура документа
*   **[02_COMBAT](/02_COMBAT/)**: Матрица урона, тактическая алхимия (яды), ИИ мобов и система аггро.

*   **[05_CRAFTING](/05_CRAFTING/)**: Логика дропа (скрап вместо целых вещей), сборка чертежей и региональные кузнецы.

## Ключевые фичи (Highlights)
1. **Анти-RMT экономика:** Прогрессивные лимиты передачи золота, зависящие от времени совместной игры, и запрет на аукцион для книг навыков.
2. **Тактический бой:** Матрица урона, где яд и кровотечение зависят от типа оружия (колющее vs рубящее), а мобы используют ману и тактику.
3. **Социальный контракт:** Отсутствие телепортов в группу, физическая встреча, распределение лута лидером и штраф за смерть всей пати в данже.
4. **Живая репутация:** Система, где серийные PK-шники превращаются в мобов с потерей оружия, а честная самооборона поощряется.

### ⚖️ Пример системного баланса: Матрица "Оружие vs Броня"
*Чтобы избежать единого "мета-билда", эффективность оружия и DoT-эффектов привязана к типу цели, а не к абстрактным цифрам.*

| Тип оружия | Эффективность против Тяжелой брони | Эффективность против Робы | Механика DoT |
| :--- | :--- | :--- | :--- |
| **Колющее (Рапира)** | Высокая (игнорирует часть брони через щели) | Средняя | Яд проникает в кровоток (высокий урон) |
| **Рубящее (Топор)** | Низкая (соскальзывает) | Очень высокая | Кровотечение (требует открытой раны) |
| **Дробящее (Молот)** | Средняя (снижает выносливость/стан) | Высокая | Нет DoT, только контроль стамины |

## Обо мне
Системный геймдизайнер с фокусом на:
- Глубокие экономические циклы и защиту от RMT

- Социальные механики и клановое взаимодействие

Этот документ демонстрирует мои навыки проектирования комплексных игровых систем от концепта до технической реализации.
