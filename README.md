## 🇷🇺 О проекте
Этот репозиторий содержит Game Design Document (GDD) для изометрической Action-RPG, ориентированной на ПК (клавиатура + мышь). 

**Ключевые принципы:**
- **Тактическая глубина без "пианино"**: Управление через WASD + 2 кнопки мыши + кувырок. Вес, коммитмент и последствия каждого действия.
- **Саморегулируемая экономика**: Единая валюта (Золото), 7-дневное окно торговли, ваучеры наставничества и глобальные серверные цели (Жадная Фея).
- **Модульная прогрессия**: Система "Книг навыков" вместо гигантских древ. Расовые пороговые синергии.
- **Честный крафт**: Болванки + импринты навыков. NPC-крафт без гринда профессий.
- **Духовный наследник**: Механики, вдохновленные *Blade of Darkness* и классическими ARPG, но лишенные их архаичных недостатков.

## 🇬🇧 About the Project
This repository contains the Game Design Document (GDD) for an isometric Action-RPG, designed strictly for PC (Keyboard + Mouse).

**Core Principles:**
- **Tactical depth without "piano controls"**: WASD + 2 mouse buttons + dodge roll. Weight, commitment, and consequences for every action.
- **Self-regulating economy**: Single currency (Gold), 7-day trade window, mentorship vouchers, and global server goals (The Greedy Fairy).
- **Modular progression**: "Skill Books" system instead of massive skill trees. Racial threshold synergies.
- **Honest crafting**: Blanks + skill imprints. NPC crafting without profession grinding.
- **Spiritual successor**: Mechanics inspired by *Blade of Darkness* and classic ARPGs, but stripped of their archaic flaws.
